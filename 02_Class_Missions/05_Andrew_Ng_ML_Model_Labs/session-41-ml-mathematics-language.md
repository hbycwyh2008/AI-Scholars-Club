# Session 41 — ML Mathematics Language

## Goal

Translate an ML problem from words into task type, data objects, notation, shapes, baseline, loss, and evaluation metric.

## Learn

Introduce `m`, `n`, `X`, `y`, feature vectors, parameter vectors, prediction, loss/objective, and evaluation metric. Emphasise that **training loss and competition/evaluation metric are not automatically the same thing**.

## Practice

Given two small tabular tasks, students write:

- input and required output;
- label availability and task type;
- shape of `X` and `y`;
- a simple baseline;
- plausible loss/objective;
- evaluation metric.

## Rebuild

Close notes. Give a fresh problem statement and a tiny table. Students independently create the complete task contract and notation/shape ledger.

## Share

Students explain one symbol, one shape, and why their metric is appropriate. Peers challenge any ambiguity between model objective and real task success.

## Evidence

- task contract;
- notation/shape ledger;
- equation/code translation for one simple prediction;
- one limitation or unanswered question.

## Exit Check

Student can look at `X.shape` and `y.shape`, explain what every dimension means, and state what the model is trying to predict before selecting an algorithm.
