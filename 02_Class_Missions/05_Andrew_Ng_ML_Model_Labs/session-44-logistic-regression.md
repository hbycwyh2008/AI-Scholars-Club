# Session 44 — Logistic Regression

## Goal

Connect logits, sigmoid probability, decision boundaries, and log loss to binary classification.

## Learn

Interpret the sigmoid as mapping a linear score to a probability-like output. Distinguish probability estimation from the threshold used to make a class decision.

## Practice

- compute sigmoid values for simple logits;
- predict how feature/weight changes move probability;
- inspect a 2D decision boundary;
- fit a logistic-regression baseline.

## Rebuild

Students receive a fresh binary-classification dataset and independently create a valid split, baseline, logistic model, and first metric report.

## Share

Explain why “0.5” is not a universal optimal threshold and identify one assumption/limitation of a linear decision boundary.

## Evidence

- probability/logit trace;
- classifier notebook;
- decision-boundary or coefficient explanation;
- first error observations.

## Exit Check

Student can explain what logistic regression outputs, how a threshold turns probabilities into labels, and when a non-linear model may be needed.
