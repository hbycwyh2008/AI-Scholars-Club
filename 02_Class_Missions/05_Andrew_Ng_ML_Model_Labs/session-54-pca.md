# Session 54 — Principal Component Analysis

## Goal

Understand centring, projection, variance direction, and PCA as a representation tool rather than a magic accuracy button.

## Learn

Use geometric intuition for principal directions and projection. Discuss scaling, explained variance, information loss, and the difference between dimensionality reduction and supervised prediction.

## Practice

- centre a tiny 2D dataset conceptually;
- project points onto a supplied direction;
- compare explained-variance choices;
- inspect model/visualisation behaviour with and without PCA.

## Rebuild

Students apply PCA inside a split-safe pipeline to an appropriate dataset and compare against the non-PCA baseline under the same validation design.

## Share

Defend whether PCA helped compression, visualisation, runtime, or prediction—and identify what information may have been lost.

## Evidence

- projection/variance explanation;
- split-safe PCA pipeline;
- baseline comparison;
- limitation statement.

## Exit Check

Student can explain what PCA preserves, what it discards, and why it must be fitted using training data rather than the full dataset.
