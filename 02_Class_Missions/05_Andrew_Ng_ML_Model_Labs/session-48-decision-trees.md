# Session 48 — Decision Trees

## Goal

Understand recursive splitting, impurity/entropy intuition, and tree overfitting.

## Learn

Use class proportions to reason about impurity and information gain. Explain how a split partitions feature space and why deep trees can memorise training data.

## Practice

- calculate impurity/entropy for small nodes;
- compare candidate splits;
- trace a prediction through a fitted tree;
- inspect depth/leaf-size effects.

## Rebuild

Fit a decision-tree baseline on a fresh tabular classification task using the same validation protocol as an earlier linear model.

## Share

Explain one split in task language and compare tree errors with logistic-regression errors.

## Evidence

- split/impurity calculation;
- tree baseline;
- controlled model comparison;
- overfitting diagnosis.

## Exit Check

Student can explain why a split is useful, identify tree overfitting, and justify whether a tree adds value beyond the simpler baseline.
