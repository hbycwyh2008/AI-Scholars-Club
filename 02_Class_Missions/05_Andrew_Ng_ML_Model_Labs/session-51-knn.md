# Session 51 — K-Nearest Neighbours

## Goal

Connect distance, feature scaling, neighbourhood size, and local prediction.

## Learn

Interpret KNN as a lazy/local method. Review Euclidean distance and explain why feature scale can dominate distance.

## Practice

- calculate distances for a tiny example;
- classify/predict from nearest neighbours;
- compare unscaled and scaled results;
- vary `k` and observe bias/variance behaviour.

## Rebuild

Students receive a small task where KNN is plausible and fit a baseline only after stating why distance is meaningful for the features.

## Share

Explain one case where KNN is a useful baseline and one where dimensionality/runtime/feature meaning makes it weak.

## Evidence

- distance calculation;
- scaling comparison;
- `k` experiment;
- task-suitability note.

## Exit Check

Student can explain why scaling matters and how neighbourhood size changes model behaviour.
