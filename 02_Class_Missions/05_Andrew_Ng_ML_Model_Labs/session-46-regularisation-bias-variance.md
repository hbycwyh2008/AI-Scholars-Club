# Session 46 — Regularisation, Bias, and Variance

## Goal

Diagnose underfitting/overfitting and use regularisation as a controlled response rather than a ritual.

## Learn

Connect model complexity, training error, validation error, bias, variance, and parameter penalties. Interpret regularisation strength as a trade-off.

## Practice

- classify learning-curve patterns;
- predict the effect of increasing/decreasing regularisation;
- compare train/validation scores for several controlled settings;
- identify when more data, new features, or a different model is more appropriate than tuning regularisation.

## Rebuild

Students run one controlled regularisation experiment on a familiar model and write the diagnosis before looking at the final result.

## Share

Defend the next action from evidence: simplify model, increase capacity, adjust regularisation, improve data/features, or collect more data.

## Evidence

- learning-curve diagnosis;
- controlled comparison table;
- next-action memo;
- limitation statement.

## Exit Check

Student can distinguish high bias from high variance and choose an intervention that addresses the observed failure pattern.
