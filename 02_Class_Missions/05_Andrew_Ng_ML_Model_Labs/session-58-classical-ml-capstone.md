# Session 58 — Classical ML Capstone

## Goal

Demonstrate transfer across task recognition, mathematical reasoning, modeling, evaluation, and controlled iteration.

## Mixed Assessment

Students receive several short unfamiliar scenarios and one practical dataset. Without model names in the prompts, they must identify:

- input / output / labels;
- task family;
- valid validation design;
- simplest credible baseline;
- metric;
- candidate model families;
- likely failure modes.

## Practical Capstone

For the dataset, students independently:

1. create a task contract and data audit;
2. establish a reproducible baseline;
3. compare at least two justified classical models;
4. perform one representative mathematical trace or calculation;
5. analyse errors;
6. make one controlled improvement;
7. write a concise model card and limitations section.

## Oral Defense

Teacher asks students to explain why they did **not** choose one plausible alternative model or metric and what evidence would make them change their decision.

## Evidence

- mixed model-recognition assessment;
- reproducible notebook/code;
- model-comparison table;
- mathematical trace;
- error analysis;
- model card;
- oral defense notes.

## Exit Gate

Student passes only if the workflow is valid and defensible. A high score does not compensate for leakage, invalid evaluation, irreproducibility, or inability to explain model behaviour.
