# Session 47 — Neural-Network Bridge

## Goal

Use the Machine Learning Specialization neural-network material to bridge classical models and later deep learning.

## Learn

Represent a small network as repeated linear transformations plus activations. Track input, hidden, and output shapes. Connect a neuron to weighted-sum reasoning already learned.

## Practice

- trace one tiny forward pass;
- label tensor/vector shapes;
- compare linear/logistic models with a one-hidden-layer network;
- identify what extra capacity the hidden layer introduces.

## Rebuild

Students reconstruct the forward-pass logic for a tiny network from a diagram or equations, then verify with code.

## Share

Explain why a neural network is not automatically better than a classical baseline and what evidence would justify additional complexity.

## Evidence

- forward-pass calculation;
- shape ledger;
- baseline-vs-network reasoning note;
- one limitation/failure risk.

## Exit Check

Student can explain a small feed-forward network as composed functions and track shapes without relying on framework syntax.
