# Session 42 — Linear Regression

## Goal

Connect weighted sums, slope/intercept, residuals, and mean squared error to a real regression baseline.

## Learn

Study prediction as a weighted combination of features. Define residual, squared error, and MSE. Distinguish the regression model from the metric used to judge the actual task.

## Practice

- compute several predictions by hand;
- compute residuals and MSE;
- compare predictions before and after changing one coefficient;
- fit a simple regression model on a small dataset.

## Rebuild

On a fresh regression task, students identify `X`, `y`, baseline, split, and metric; then fit and evaluate a linear model without a complete starter solution.

## Share

Explain what one coefficient means in context and identify a situation in which a linear model is an intentionally useful baseline even if it will not be the final model.

## Evidence

- hand prediction and MSE calculation;
- valid regression baseline notebook;
- coefficient interpretation;
- one error/residual observation.

## Exit Check

Student can explain the prediction rule, calculate MSE on a tiny example, and defend why linear regression is or is not a sensible baseline for a new task.
