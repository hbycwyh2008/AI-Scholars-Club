# Session 49 — Random Forests

## Goal

Understand bagging, random feature selection, averaging/voting, and variance reduction.

## Learn

Compare one unstable decision tree with an ensemble of diverse trees. Explain why bootstrap samples and feature randomness can reduce variance.

## Practice

- sketch how several trees vote/average;
- compare train/validation results for a single tree and random forest;
- inspect feature importance cautiously;
- identify cost and interpretability trade-offs.

## Rebuild

Using the same dataset/split as Session 48, students fit a random forest and change only one justified parameter.

## Share

Defend whether the forest improvement is meaningful enough to justify extra complexity/runtime.

## Evidence

- bagging/voting explanation;
- tree-vs-forest comparison table;
- one controlled parameter experiment;
- limitations note.

## Exit Check

Student can explain how a random forest differs from one tree and why diversity among trees matters.
