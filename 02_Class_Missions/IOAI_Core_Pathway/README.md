# IOAI Core Pathway — Student Mission Map

This folder is the student-facing map for the IOAI-focused route. Your teacher assigns only the resource sections needed for the current mission.

## Learning Route

```text
Python readiness
→ Data Science with Python
→ Advanced Python and AI
→ AI conceptual map + task recognition
→ ML workflow bootcamp
→ Andrew Ng Machine Learning
→ AAAMLP competition workflow
→ evaluation / features / tuning / ensembling
→ Deep Learning
→ PyTorch
→ IOAI competition projects
```

## What You Must Be Able to Do

Watching a video or finishing an external platform lesson is not the goal. You should increasingly be able to do this without step-by-step prompts:

```text
understand the problem
→ identify input / output / labels
→ choose the task type
→ inspect the data
→ design valid validation
→ build a baseline
→ choose the metric
→ analyse errors
→ make one controlled improvement
→ compare results
→ document and defend the decision
```

## Repeated Task-Recognition Routine

For unfamiliar problems, answer:

1. What is the input?
2. What output is required?
3. Are labels/targets available?
4. What task family is this?
5. What simple baseline should we try first?
6. What metric should judge success?

Do not choose a model before you understand the task and evaluation.

## Evidence You Will Produce

Depending on the mission:

- code/notebook commits;
- task cards;
- data audits;
- validation plans;
- baseline reports;
- experiment logs;
- model comparisons;
- error analyses;
- model cards;
- oral explanations;
- competition postmortems.
