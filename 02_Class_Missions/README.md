# Class Missions — Start Here

## Default Route (club core)

Follow the **[Club Pathway G10–G12](../00_Course_Overview/Club_Pathway_G10-G12.md)**. Year-band folders (`Year_A_G10/`, `Year_B_G11/`, `Year_C_G12/`) are being authored.

Until year-band packets exist, reuse **legacy packets** via the [Legacy Session Migration Map](../00_Course_Overview/Legacy_Session_Migration_Map.md).

## Normal Use

```text
confirm year band + session number
→ open migration map for legacy packet link (interim)
→ or open year-band SESSION_LAUNCHER when available
→ teach 75-minute seven-block flow
→ submit named evidence
```

Read [How to Use Class Missions](HOW_TO_USE_CLASS_MISSIONS.md) once before teaching.
