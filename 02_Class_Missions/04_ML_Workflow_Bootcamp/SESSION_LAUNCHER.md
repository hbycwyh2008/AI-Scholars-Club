# Unit 4 — ML Workflow Bootcamp Mission Launcher

| Mission | Focus | Required evidence | Portfolio evidence |
|---|---|---|---|
| WF-1 | Problem framing | task cards | project question, user, X/y, metric |
| WF-2 | Data inspection / EDA | data audit + risk list | provenance, license, audit figure |
| WF-3 | Validation design and leakage | validation decision memo | split rationale and test-set policy |
| WF-4 | Simple baseline first | baseline notebook | reproducible baseline |
| WF-5 | Metric selection | metric justification | metric definition and limitations |
| WF-6 | Error analysis | error-slice table | failure examples and interpretation |
| WF-7 | Controlled improvement | experiment log | feature/model/regularization comparison |
| WF-8 | Independent end-to-end challenge | notebook + oral defense + postmortem | project narrative, limitations, clean-run instructions |

For suitable linear models, compare L1/Lasso, L2/Ridge, and Elastic Net; select regularization strength with validation/CV, never the final test set. Explain the complexity trade-off.
