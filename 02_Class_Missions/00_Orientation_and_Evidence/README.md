**Scheduled sessions:** 1–2

## Start Here

[**Open the Phase 0 Session Launcher**](SESSION_LAUNCHER.md)

Open the Session Launcher to select Session 1 or 2. Before Session 1, complete the [NOAI Round 1 full diagnostic](https://docs.google.com/forms/d/e/1FAIpQLScKR5tkKql28GpgKaRADniswegPkLn09Ty-i1rb3mPbA60W5A/viewform).

## Purpose

Begin with direct evidence of the destination and the student's current baseline. Before Session 1, students complete a 120-minute, no-search, no-IDE, no-generative-AI [NOAI Round 1 full diagnostic](https://docs.google.com/forms/d/e/1FAIpQLScKR5tkKql28GpgKaRADniswegPkLn09Ty-i1rb3mPbA60W5A/viewform). Session 1 uses the result to make NOAI/IOAI difficulty, competition stages, course purpose, learning routes, and evidence expectations concrete. Session 2 then establishes the student repository, evidence system, Bohrium access, Jupyter environment, and responsible-AI routine before CS50P begins.

## Gate

By the end of Phase 0, students can interpret their diagnostic result, name one current strength and two priority gaps, explain the relationship between NOAI and IOAI, compare the main competition stages and capability demands, state why this course is structured from foundations to competition execution, identify their assigned route, create and use their repository, run Python, locate assigned resources, and submit reproducible evidence without copying a complete solution.
