# Prerequisite Map — G8 & G9 → AI Scholars Club

AI Scholars Club assumes students completed the school CS pathway **before** G10:

| Grade | Course | What students should already bring |
|---|---|---|
| **G8** | Software Design, Development & AI | Python basics, web stack, HCI needfinding, Figma, GitHub workflow, AI literacy (capability, hallucinations, disclosure) |
| **G9** | AP Computer Science Principles | Algorithms, data, abstraction, computing impacts, debugging discipline |

## Entry diagnostic (Session 3)

Session 3 is a **routing diagnostic**, not a full re-teach of CS50P.

| Area | If strong | If gap |
|---|---|---|
| Python syntax, functions, files | Skip to Session 4 | Assign `02_Class_Missions/01_CS50P_Python/` gap packets (Sessions 3–12 legacy) |
| NumPy / Pandas | Start Session 4 | Use Sessions 13–18 legacy packets |
| Computing impacts / ethics | Start Mitchell seminars on schedule | Add G9 impact review + Session 13 bridge |
| GitHub / evidence | Confirm in Session 2 | Use legacy Sessions 1–2 orientation packets |

**Rule:** gap-fill uses **legacy packets** only for identified weaknesses. Do not run the full 78-Session pipeline by default.

## Skills assumed on Day 1

Students should be able to:

- clone a repo, commit, and push with a meaningful message
- explain variables, conditionals, loops, and functions in Python
- describe one HCI needfinding method and one design artifact
- state when AI help is allowed and how to disclose it
- read a simple algorithm or flowchart and predict behaviour

## Skills explicitly taught in club (not prerequisites)

- sklearn and PyTorch workflows
- classical and deep ML model families
- computer vision for robotics
- advanced evaluation, deployment, and capstone research

## Placement options

| Student profile | Suggested entry |
|---|---|
| G10, completed G8 + G9 | Year A Session 1 |
| G11 transfer with strong G8/G9 | Diagnostic → Year A Session 8 or Year B Session 25 |
| G12 transfer with ML experience | Teacher interview + diagnostic → Year B or Year C entry |
| Competition-focused add-on | [Competition Enrichment](Competition_Enrichment_Optional.md) after Year B minimum |

## Connection to school pathway poster

This club is the **G10–G12 AI Track** on the school CS Curriculum Pathway (G6–12):

- ML foundations → Year A
- Ethics → Year A Unit A3
- Computer vision + VEX → Year B Units B3–B4
- Advanced AI → Year C Unit C1
- Competitions → optional enrichment module
