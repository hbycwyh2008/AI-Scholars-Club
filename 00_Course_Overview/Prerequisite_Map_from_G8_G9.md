# Prerequisite Map — G8 & G9 → AI Scholars Club

AI Scholars Club assumes students completed the school CS pathway before G10:

| Grade | Course | What students should already bring |
|---|---|---|
| **G8** | Software Design, Development & AI | Python basics, web stack, HCI needfinding, Figma, GitHub workflow, AI literacy |
| **G9** | AP Computer Science Principles | algorithms, data, abstraction, computing impacts, debugging discipline |

## Entry Diagnostic (Session 3)

Session 3 is a **routing diagnostic**, not the start of a mandatory Python course.

| Area | If strong | If gap |
|---|---|---|
| Python syntax, functions, loops, collections | Continue to Session 4 | Assign targeted **CodeHS Data Science with Python — Basic Python Bootcamp** practice and/or selected legacy Python packet |
| NumPy | Continue with Session 4 challenge level | Use the Session 4 NumPy bridge and extra rebuild practice |
| Pandas / data handling | Continue to Session 5 | Assign selected CodeHS Data Science with Python practice |
| Computing impacts / ethics | Start Mitchell seminars on schedule | Add targeted G9 impact review |
| GitHub / evidence | Confirm in Session 2 | Use legacy orientation/evidence packet |

**Rule:** remediation is targeted to an identified weakness. Do not require the whole cohort to complete a full external Python course.

## Skills Assumed on Day 1

Students should be able to:

- clone a repo, commit, and push with a meaningful message;
- explain variables, conditionals, loops, and functions in Python;
- read and trace a short Python program;
- describe one HCI needfinding method and one design artifact;
- state when AI help is allowed and how to disclose it;
- read a simple algorithm or flowchart and predict behaviour.

## Skills Explicitly Taught in the Club

- NumPy arrays, shapes, indexing, and vectorisation;
- Pandas and data-quality workflows;
- scikit-learn modeling workflows;
- classical and deep ML model families;
- PyTorch training discipline;
- computer vision for robotics;
- advanced evaluation, deployment, research, and capstone work.

## External Resource Boundary

- **CodeHS Data Science with Python** is a practice platform, not the curriculum spine.
- Its **Basic Python Bootcamp** is used only when diagnostic evidence shows a need.
- **CS50P** is optional reference/extension material; there is no required pre-class viewing sequence.
- Students who are already strong in Python should move forward rather than complete redundant introductory exercises.

## Placement Options

| Student profile | Suggested entry |
|---|---|
| G10, completed G8 + G9 | Year A Session 1 |
| G11 transfer with strong G8/G9 | Diagnostic → Year A Session 8 or Year B Session 25 |
| G12 transfer with ML experience | Teacher interview + diagnostic → Year B or Year C entry |
| Competition-focused add-on | Competition Enrichment after Year B minimum |

## Connection to School Pathway

This club is the **G10–G12 AI Track** on the school CS Curriculum Pathway:

- Data + ML foundations → Year A
- Responsible AI → Year A
- Computer vision + VEX → Year B
- Advanced AI + research → Year C
- Competitions → optional enrichment
