# Legacy Competition Pathways

**Status:** archived default routes — superseded by [Club Pathway G10–G12](Club_Pathway_G10-G12.md)

The repository originally shipped as a **NOAI / IOAI preparation academy** (78 sessions, competition-first). That design remains available for the [optional Competition Enrichment module](Competition_Enrichment_Optional.md) but is **no longer the club default**.

## Why this changed

| Problem (legacy) | Club redesign |
|---|---|
| Competition identity in Session 1 | Club charter + portfolio in Session 1 |
| 10-session CS50P re-teach | G8/G9 prerequisite + Session 3 diagnostic |
| 14-session Bohrium overlap | Demoted to optional Mandarin enrichment |
| No G10/G11/G12 year bands | 24 sessions × 3 years |
| No VEX / robotics vision | Year B Unit B4 |
| Ethics as side topic | Year A Unit A3 (6 sessions) |
| Daily drill machinery for all | Enrichment-only |
| 78 sessions ≈ 2–3 years monolith | 72-session core + 8–12 optional |
