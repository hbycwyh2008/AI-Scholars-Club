# AI Scholars Club — Learning Outcomes

The canonical progression is competency-based:

```text
L1 — Understand & Code
→ L2 — Build
→ L3 — Solve Unseen Problems
→ L4 — Create New Knowledge
```

A student advances because the required output and evidence are demonstrated, not because a named course was completed.

## L1 — AI Literacy & Python Foundations

By the end of L1, a student can:

1. explain basic AI concepts in their own words;
2. distinguish introductory AI, machine learning, and deep-learning ideas;
3. describe simple AI systems in terms of input, process/model, and output;
4. identify the broad type of a simple AI problem;
5. write, run, debug, and modify basic Python programs using variables, conditionals, loops, functions, strings, lists, and dictionaries;
6. use basic files/libraries/notebooks with guidance;
7. discuss important AI limitations and responsible-use concerns without relying on slogans.

**Required evidence:** Python coding task + AI literacy evidence + simple task-identification activity.

## L2 — Applied Machine Learning

By the end of L2, a student can:

1. frame a common ML problem;
2. inspect, clean, and explore a dataset;
3. establish a defensible baseline;
4. select and train an appropriate classical ML model;
5. choose an appropriate evaluation metric;
6. use train/validation/test discipline;
7. diagnose basic data/model problems;
8. make and evaluate a justified improvement;
9. preserve a reproducible workflow.

**Required evidence:** complete ML project/notebook + rationale + error analysis + short defense.

## L3 — Advanced AI & Competition

By the end of L3, a student can:

1. approach an unfamiliar AI/ML task without being given the full method;
2. identify the task, scoring rule, constraints, and likely baseline;
3. design a validation strategy;
4. choose between classical ML and deep-learning approaches when appropriate;
5. work with PyTorch and selected CV/NLP models;
6. perform model/feature selection;
7. tune systematically rather than randomly;
8. use ensembling when justified;
9. compare controlled experiments;
10. document a reproducible solution and postmortem.

**Required evidence:** unseen or competition-style challenge + reproducible solution + decision log + presentation/postmortem.

## L4 — AI Research

L4 is qualification/invitation-based and does not need to run every year.

By the end of L4, a student can:

1. identify a tractable research question;
2. read and position relevant research papers;
3. reproduce a prior result;
4. define an appropriate baseline;
5. propose a small modification or hypothesis;
6. design a controlled experiment or ablation;
7. analyse results and limitations;
8. communicate the work in research style.

**Required evidence:** paper-reading record + reproduction repo + modified experiment + research-style report/poster/presentation.

## Promotion Principle

```text
Course completion ≠ mastery.
Demonstrated output + evidence = promotion.
```

External resources are selected only when they directly improve the target output of a level.
