# Learning Outcomes

By the end of the **AI Scholars Club core pathway** (72 sessions, G10–G12), a prepared student can:

## Year A (G10)

1. Run a reproducible **tabular ML workflow** (task → data quality → baseline → compare → diagnose).
2. Explain **training data, bias, and model limitations** using evidence, not slogans.
3. Apply the school **AI use policy** — disclose help, rebuild independently, audit claims.
4. Produce a **model card** and defend one scholar project orally.

## Year B (G11)

5. Build and debug a **PyTorch training loop** from memory-level understanding.
6. Train and evaluate a **computer vision model** with error analysis.
7. Connect **camera input → perception → action** in a robotics or simulation context.
8. Document one **applied vision project** with reproducible evidence.

## Year C (G12)

9. Explain **transformers, generative AI, and RAG** at an intuition level with stated limits.
10. Run **advanced evaluation** — diagnosis before tuning; subgroup and bias checks.
11. Ship a **capstone** with README, reproducibility notes, and stakeholder communication.
12. Present a **portfolio** suitable for college, internship, or research applications.

## Optional competition enrichment

Students who complete the optional module may additionally:

- solve NOAI Round 1-style knowledge and reasoning items;
- execute timed open-ended modeling under official constraints;
- pass model-recognition and workflow gates from the legacy pipeline.

These outcomes are **not required** for club completion.

## What we do not claim

- Club completion ≠ automatic NOAI / IOAI qualification
- Running supplied notebooks ≠ mastery without independent rebuild
- AI-generated work without understanding ≠ portfolio evidence
