# Daily Lesson Plans

The student-facing mission file is the operational lesson sheet. Teachers may add timing adjustments, anticipated misconceptions, oral-check prompts, and extension tasks here.

## IOAI Core Pathway

Use the [IOAI Core Pathway lesson-plan index](IOAI_Core_Pathway/README.md) for the focused competition-preparation sequence.

The plans cover:

1. CodeHS Data Science with Python
2. CodeHS Advanced Python and AI Programming
3. Melanie Mitchell + task recognition
4. ML Workflow Bootcamp using Müller + ML Zoomcamp
5. Andrew Ng Machine Learning Specialization
6. AAAMLP competition workflow
7. evaluation, feature engineering, tuning, and ensembling
8. Andrew Ng Deep Learning Specialization
9. PyTorch
10. IOAI competition projects

Each plan preserves **Learn → Practice → Rebuild → Share** and defines an exit gate based on transferable evidence rather than course completion.
