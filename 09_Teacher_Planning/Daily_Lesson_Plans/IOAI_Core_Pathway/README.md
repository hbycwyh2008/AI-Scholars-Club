# IOAI Core Pathway — Teacher Lesson Plans

These plans operationalise the [IOAI Core Learning Path](../../../00_Course_Overview/IOAI_Core_Learning_Path.md).

They use the club's shared learning cycle:

```text
Learn → Practice → Rebuild → Share
```

The lesson count is a planning default, not a fixed competition calendar. Compress or expand only after inspecting student evidence.

## Why AI History Comes Immediately After the Introduction

Students first need an **AI conceptual map**: symbolic AI, machine learning, neural networks, CV, NLP, RL, and the limits of current systems. That map gives later programming, data, and model work a place to fit.

The formal six-question ML task-recognition routine begins in Unit 2, once students have enough data vocabulary to reason about labels, baselines, and metrics.

## Standard Evidence Rule

Every lesson must produce evidence beyond viewing or copying. Use one or more of:

- independent code/notebook rebuild;
- task card;
- data audit;
- experiment log;
- hand calculation / trace;
- metric or validation justification;
- error analysis;
- model comparison;
- oral defense;
- postmortem.

## Recurring Task-Recognition Drill

From Unit 2 onward, repeatedly use:

```text
input → output → labels? → task type → baseline → metric
```

Do not reveal the task family in the prompt. Students infer it from the problem statement. During Unit 1, use lighter problem-framing questions rather than forcing baseline/metric vocabulary before it has been taught.
