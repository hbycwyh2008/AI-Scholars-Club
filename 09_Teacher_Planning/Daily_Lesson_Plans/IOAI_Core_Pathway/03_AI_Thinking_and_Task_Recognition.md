# Unit 3 — AI Thinking + Task Recognition

**Suggested length:** 8 × 70–75 minutes + recurring 5–10 minute drills  
**Core text:** Melanie Mitchell, *Artificial Intelligence: A Guide for Thinking Humans*  
**Existing lesson bank:** [`02_Class_Missions/04_AI_History_and_Thinking_Humans`](../../../02_Class_Missions/04_AI_History_and_Thinking_Humans/README.md)

This unit builds the **AI conceptual map** while task-recognition drills build the habit of translating a real problem into an ML contract.

## Seminar Sequence

Use the existing eight lesson packets:

1. What counts as intelligence?
2. Neural networks, machine learning, and AI cycles
3. How machines recognise images
4. What did the model actually learn?
5. Reward, games, and reinforcement learning
6. Language processing and understanding
7. Common sense, abstraction, and analogy
8. Whole-book synthesis: how intelligent is AI?

Do not replace these seminars with summaries. Students read, retrieve, discuss claims, inspect evidence, and revise their own explanations.

## Task-Recognition Overlay

Add one short unfamiliar problem to most meetings. Students answer **before** any model names are supplied:

```text
1. What is the input?
2. What output is required?
3. Are target labels available?
4. What task family best matches the requirement?
5. What is the simplest credible baseline?
6. What metric would reflect success?
```

## Drill Progression

| Stage | Problem style | What changes |
|---|---|---|
| A | clear tabular classification/regression | establish routine |
| B | clustering / anomaly / dimensionality reduction | labels are less obvious |
| C | image/text/audio scenarios | modality changes but workflow persists |
| D | ambiguous real-world prompt | students must ask clarifying questions |
| E | competition-style prompt with scoring rule | metric and validation become part of task recognition |

Never write prompts that give away the answer with phrases such as “there are no labels, so use clustering.” Students infer the structure from the situation.

## Evidence

- reading evidence / claim audits from the existing Mitchell packets;
- task-recognition answer records;
- oral explanation of why a tempting alternative task/model is wrong;
- one final AI concept map connecting symbolic AI, ML, deep learning, RL, CV, NLP, and current limitations.

## Exit Gate

Student can:

- explain major AI traditions without treating all AI as deep learning;
- distinguish task definition from model selection;
- infer task family from an unfamiliar scenario;
- propose a baseline and metric without being handed model names;
- state what additional evidence is needed when the prompt is ambiguous.
