# Unit 0 — Course Introduction and Orientation

**Suggested length:** 1 × 70–75 minutes  
**Purpose:** establish the course map, competition context, evidence expectations, and learning language before students begin AI history.

## Learning Goals

By the end of this session, students can explain:

- what the IOAI-focused pathway is preparing them to do;
- how the course moves from AI concepts to data, ML workflow, models, deep learning, and competition tasks;
- the shared learning cycle: `Learn → Practice → Rebuild → Share`;
- what counts as evidence of mastery;
- why a score or completed external course is not the same as understanding.

## Lesson Flow

| Block | Activity | Evidence |
|---|---|---|
| Course map | Walk through the complete IOAI pathway and show where each major resource fits | annotated pathway map |
| First-look challenge | Give one unfamiliar IOAI/NOAI-style problem or historical first-round item without teaching the solution | initial reasoning record |
| Evidence rules | Explain notebooks, commits, task cards, experiment logs, model cards, error analyses, and oral defense | evidence checklist |
| Learning cycle | Demonstrate `Learn → Practice → Rebuild → Share` on a very small example | one mini rebuild |
| Reflection | Students state what they already know, what is unfamiliar, and what they expect to learn | baseline reflection |

## Teacher Notes

- Do not turn the introduction into a long syllabus lecture.
- The first-look challenge is diagnostic and motivational; it is not graded for mastery.
- Do not teach model names merely to help students finish the challenge.
- Make the course architecture visible from day one so later topics have a place in the mental map.

## Exit Gate

Students can describe the route in their own words:

```text
course introduction
→ AI history / conceptual map
→ data and Python fluency
→ ML workflow
→ model principles
→ competition decision-making
→ deep learning / PyTorch
→ IOAI task execution
```

They also understand that every later phase requires evidence beyond watching or copying.
