# Core Teaching Principles — Do Not Replace Student Thinking

This document defines a **shared teaching rule for all lesson plans** in the AI Scholars Club.

The central principle is:

> **The teacher must not complete the student's first cognitive processing for them.**

Teaching is not the same as withholding explanation. The teacher still explains, models, corrects, and extends. The difference is **when** that explanation happens.

Whenever students are capable of making a first attempt, the lesson should require that attempt **before** the teacher supplies the complete interpretation.

---

## 1. Default Learning Sequence

Use this sequence whenever the content allows it:

```text
encounter the problem / reading / example
→ think independently
→ form a provisional understanding
→ explain or reconstruct it
→ expose uncertainty or error
→ teacher diagnoses and corrects
→ apply the corrected understanding
→ retrieve or explain again
```

The teacher's explanation is therefore usually a **response to student thinking**, not a substitute for student thinking.

---

## 2. The Teacher's Role

The teacher is primarily a:

- **designer** — creates tasks that require students to think;
- **diagnostician** — listens for incomplete models, misconceptions, and missing connections;
- **corrector** — gives precise correction when evidence shows it is needed;
- **connector** — links student discoveries to the larger conceptual structure;
- **model** — demonstrates expert reasoning when the reasoning itself is new or inaccessible;
- **gatekeeper** — checks whether students can reconstruct and transfer the idea independently.

The teacher is **not primarily an information broadcaster**.

---

## 3. The Planning Question

Before directly explaining a section, ask:

> **If I explain this now, am I doing cognitive work that the student could reasonably attempt first?**

If the answer is **yes**, redesign the block so that students first:

- predict;
- classify;
- retrieve;
- explain;
- compare;
- trace;
- debug;
- build;
- argue from evidence;
- or attempt a solution.

Then teach from what their attempt reveals.

If the answer is **no** — because the idea requires missing prerequisite knowledge, a safety-critical correction, inaccessible context, or expert modelling — direct instruction is appropriate.

---

## 4. Do Not Confuse Coverage with Learning

A lesson is not successful because every page, term, or slide was covered.

Prefer:

```text
less content
+ slower pace
+ more student processing
+ visible evidence of understanding
```

over:

```text
more content
+ faster teacher explanation
+ passive listening
+ no evidence of reconstruction
```

It is acceptable to reduce scope or slow pacing when doing so creates genuine student reasoning.

---

## 5. Pre-Reading / Pre-Learning Rule

When a lesson requires preparation, class time should **use** that preparation rather than repeat it.

Default pattern:

```text
pre-read / pre-watch / pre-explore
→ preparation evidence
→ retrieval
→ student explanation
→ teacher correction
→ application
→ retrieval again
```

Students who do not prepare should normally complete the missing prerequisite work before joining the dependent activity.

The teacher should not erase the consequence of non-preparation by immediately giving a replacement summary.

The purpose is not punishment. The purpose is to preserve the causal link:

> **Preparation gives access to higher-value class activity.**

---

## 6. Explanation After Exposure

A strong lesson often makes misconceptions visible before correcting them.

Example:

```text
student explanation
→ teacher notices misconception
→ teacher asks a probing question
→ student revises
→ teacher gives the precise missing idea
→ student explains again
```

This is usually stronger than:

```text
teacher gives perfect explanation
→ student listens
→ class moves on
```

The correction has a cognitive target because the student already has a model to revise.

---

## 7. Just-in-Time Knowledge and Mathematics

Do not front-load large bodies of mathematics, vocabulary, or theory merely because they may eventually be useful.

Prefer:

```text
problem appears
→ current knowledge becomes insufficient
→ missing tool is identified
→ teach the required mathematics / concept
→ use it immediately
```

Mathematics is introduced as a **tool for a visible problem**, not as an isolated prerequisite catalogue.

The same rule applies to technical vocabulary and theory.

---

## 8. Direct Instruction Is Still Necessary

This principle does **not** mean that students must discover everything alone.

Use direct instruction when:

1. the concept is genuinely new and students lack the prerequisites to infer it;
2. an expert reasoning process needs to be modelled;
3. a misconception would be inefficient or unsafe to leave unresolved;
4. students have attempted the task and the evidence shows a common knowledge gap;
5. a concise explanation will unlock immediate practice;
6. the teacher is synthesising multiple student discoveries into one coherent framework.

The test is not:

> “Did the teacher talk?”

The test is:

> **“Did the teacher's explanation replace thinking students could have done themselves?”**

---

## 9. Lesson-Plan Design Standard

Every lesson plan should make clear where students perform the following cognitive work:

| Cognitive function | Evidence |
|---|---|
| First attempt | prediction, retrieval, draft explanation, trace, solution attempt |
| Externalisation | pair explanation, written reasoning, code, diagram, table, argument |
| Diagnosis | teacher observation, peer question, test failure, comparison, misconception check |
| Correction | targeted mini-lesson, hint, worked contrast, teacher model |
| Application | new scenario, transfer task, implementation, comparison |
| Reconstruction | exit retrieval, teach-back, rebuild, oral defense |

Not every lesson needs a separate labelled block for all six, but the lesson should not consist mainly of **teacher explanation → copied practice**.

---

## 10. Default Teacher Intervention Ladder

When a student is stuck, intervene in this order where practical:

1. **Ask what they currently think.**
2. **Ask for the evidence or reasoning.**
3. **Ask a narrowing question.**
4. **Point to the relevant representation, example, test, or source.**
5. **Give a hint or partial structure.**
6. **Explain the missing concept.**
7. **Have the student reconstruct the answer independently.**

Do not jump automatically from “student is stuck” to “teacher gives the answer.”

---

## 11. Evidence Before Advancement

Do not infer understanding from:

- silence;
- nodding;
- copying;
- watching;
- completing a video;
- seeing a worked solution;
- saying “I understand.”

Look instead for:

- explanation in the student's own words;
- successful retrieval without notes;
- reconstruction;
- transfer to a changed example;
- debugging;
- comparison;
- justification;
- prediction;
- oral defense.

The course should advance based on **evidence of thinking**, not exposure to content.

---

## 12. Stop Condition for Explanation

Teacher explanation should stop when students have enough structure to resume productive thinking.

Do not keep explaining merely because additional details exist.

A useful cycle is:

```text
teach only enough
→ return the problem to students
→ inspect evidence
→ teach again only if needed
```

This prevents explanation from expanding until it consumes the entire lesson.

---

## 13. One-Sentence Rule for Teachers

When planning or teaching, use this as the default check:

> **Do not think for the student when you can design a situation that makes the student think first.**
